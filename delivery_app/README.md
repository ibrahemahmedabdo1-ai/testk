# سريع ديليفري — تطبيق توصيل (Flutter)

تطبيق واحد بدورين: **عميل** و **مندوب توصيل**، مع تفعيل الحساب برمز من 6 أرقام.

## المميزات (المرحلة 1)
- تفعيل: الاسم + الهاتف + اختيار الدور + رمز تفعيل
- العميل: المتاجر ← المنتجات ← السلة ← عنوان التوصيل ← تتبع حالة الطلب
- المندوب: الطلبات المتاحة ← قبول ← تم الاستلام ← تم التسليم + عداد الأرباح
- زر التبديل بين وضع العميل والمندوب من تبويب «حسابي» (لتجربة الدورة كاملة على جهاز واحد)
- واجهة عربية RTL، تخزين محلي للبيانات

## بناء الـ APK على GitHub Actions
1. فك الضغط وارفع محتوى المجلد إلى مستودع GitHub جديد (فرع `main`).
2. افتح تبويب **Actions** — سيبدأ workflow باسم **Build APK** تلقائياً (أو شغّله يدوياً بـ Run workflow).
3. بعد انتهائه (5-10 دقائق) ستجد الـ APK في:
   - أسفل صفحة الـ run تحت **Artifacts** باسم `delivery-app-apk`
   - أو في **Releases** بالمستودع.

الـ workflow يولّد مجلد `android/` تلقائياً، فلا تحتاج لتثبيت Flutter عندك.

## تشغيل محلي (اختياري)
```
flutter create . --platforms=android
flutter pub get
flutter run
```

## ما هو تجريبي حالياً
- **الرمز**: يُولَّد محلياً ويظهر على الشاشة. للإنتاج عدّل `ActivationService` في `lib/app_state.dart` لإرسال الرمز عبر مزود OTP (SMS/WhatsApp).
- **الطلبات**: مخزنة محلياً على الجهاز، فالعميل والمندوب يشوفوا بعض فقط على نفس الجهاز. للاستخدام الحقيقي بين جهازين لازم Backend (API + قاعدة بيانات) — هذه هي المرحلة 2.
- **المتاجر والمنتجات**: بيانات نموذجية في `lib/models.dart`.
- **التوقيع**: الـ APK موقّع بمفتاح debug، مناسب للتجربة. للنشر على Google Play أضف keystore خاص بك.
